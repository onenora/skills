# Minimal skill repo: Legado novel booksource (iOS + Android)

- `SKILL.md` — skill definition (novel-only, cross iOS/Android, optional 段评)
- `scripts/legado-sim.js` — Node Legado rule simulator (search→detail→toc→content)
- `references/` — novel patterns, official rule notes, 段评 integration, validation checklist

Usage:

```bash
node scripts/legado-sim.js <书源.json>
```
